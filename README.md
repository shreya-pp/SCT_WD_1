# Interactive Navigation Menu

This project is a simple dark-mode website with an interactive navigation menu developed using HTML, CSS, and JavaScript.

![MyWebsite dark-mode preview](preview.svg)

## Features

- Fixed navigation bar
- Welcome screen shown on startup
- Home, About, Services, and Contact sections
- Dark-mode teal and coral color palette
- Hover effects and active navigation states
- Navbar style changes when scrolling
- Smooth scrolling between sections

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` - Website structure and navigation
- `style.css` - Styling and hover effects
- `script.js` - Scroll interaction
- `preview.svg` - README preview image

## Sections

- Welcome / Home
- About
- Services
- Contact

## How to Run

Open `index.html` in a web browser or use Live Server in VS Code.
